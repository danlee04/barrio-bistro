# Site photos

Drop the shop's photos here, with exactly these names. They are served straight
from `/images/...`, so replacing a file is enough — no build, no deploy step.

| File           | Where it shows                                      | Best shape                    | Aim for      |
| -------------- | --------------------------------------------------- | ----------------------------- | ------------ |
| `hero.jpg`     | Behind the headline on the home page                | Landscape, 1600×1000 or wider | Under 400 KB |
| `story.jpg`    | Beside "Our story" on the home page and on `/about` | Landscape, 1200×900           | Under 300 KB |
| `interior.jpg` | Beside "Visit" on the home page and on `/contact`   | Landscape, 1200×900           | Under 300 KB |

Notes:

- **JPG or WebP.** WebP is smaller at the same quality; either works.
- Shoot or crop **wide**, not tall: these sit beside text on a laptop.
- Faces and the dish should sit near the middle — the edges get cropped on a phone.
- Until a file is here, the page shows a plain coloured panel in its place. Nothing breaks.
- Gallery photos do **not** go here. Those are uploaded in the admin (Module 9c), so
  the shop can change them without touching the code.
